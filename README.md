Have you ever needed a grocery item, but you didn't want to check every store? Well, that is what Veggie Alert is for.
It finds groceries in stores around your area filtered by price and distance. 
If you needed to keep track of the stock of a certain item, Veggie Alert will notify you for that as well

## Built in 
- Typescript
- Tailwind
### Resources used
-Supabase
-Kroger API (Only works with Korger stores)
